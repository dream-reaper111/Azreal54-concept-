# Local lab boundaries and unverified coverage

The prepared Compose environment publishes only `127.0.0.1:${AZRAEL_PORT:-8765}`. The dashboard and tools service are on an internal network, with no container socket, host home, devices or host networking mounted. The dashboard receives read-only data/model mounts and writable project artifacts. Tools and import services use authenticated internal requests. Import workers use fixed, allow-listed source URLs; role research uses authored Stack Exchange and GitHub API query URLs, enforces response bounds, and never follows result links. Scoped Google/GitHub search operators are disabled until an authenticated admin assigns one exact domain or repository to an eligible role; they render manual links and make no outbound request. A separate external-observation broker has its own secret and egress network and accepts only one admin-approved public HTTP HEAD attempt. The internal tools service has no public-egress network. Rootless Podman uses a separate container store and Compose project `azrael54`; the host dashboard port remains a possible collision across runtimes and should be checked before startup.

The dashboard, tools and import services use non-root users, read-only root filesystems, dropped capabilities, no-new-privileges, bounded CPU/memory/processes and temporary storage. The internal Juice Shop target has no host port and is intentionally vulnerable. Containers share the host kernel; these settings are not proof of isolation or a host security audit. Images currently use mutable upstream tags and transitive dependencies are not hash-locked.

No container build or end-to-end container scan has been verified here. Docker access failed on this account. Host-side process and browser tests cannot establish runtime image behavior, network isolation or tool installation success.

Login uses a project-local random token and rotating session cookie with HttpOnly and SameSite Strict. Mutation endpoints check Host, Origin and a custom request header. Sessions and approval history are process-local; restarts lose them, while evidence files remain. Evidence files are not tamper-proof audit storage. Local HTTP is intended for loopback access, not public deployment. No TLS or multi-user authorization is implemented.

Approvals bind role, section, exact operation and target; expire after five minutes; and permit one attempt. A role name or SLM output grants no privileges. Only named internal web-lab recipes and the separately approved external HTTP-header recipe can execute. No arbitrary shell, caller-selected flags, source-code execution, elevated host operations or hardware access is accepted. The external target is explicitly supplied and approved by the admin; public DNS addresses are checked and pinned, and redirects are disabled. Arbitrary repository installation remains plan-only.

Tool subprocesses have bounded duration and output. The broker retains a process owner until group cleanup and wait complete; unresolved cleanup blocks subsequent runs. Stop the tools container using Compose for emergency shutdown. There is no in-dashboard emergency-stop endpoint or cleanup-retry interface yet.

Public feed and downloaded documentation text are untrusted reference inputs. Generated answers are unverified; retrieved text is not executable policy. Publication timestamps and retrieval timestamps remain distinct. Feed failures do not silently become successful cached responses. Public evidence retrieval is not training or proof of target exposure.

Use credentials issued to your own accounts; no leaked/shared API keys are included. Transport authentication tokens are not included in model context. The project does not upload your repository or binaries to third-party analysis services. Download archives and extracted trees are data until a future explicitly scoped installation mechanism exists.

Directive profiles are perspectives, not permission grants. Raw metadata worker files remain restricted in collection-inbox pending privacy/license review; they are excluded from packaged archives. The normalized evidence store has separate review, version, dataset-membership, deletion and manually applied retention boundaries. Stored record revisions do not establish that corrections/retractions or independent corroboration were exhaustively checked.

Council reports preserve generated proposals and admin decisions without applying source changes or execution grants. The hierarchy and directive engine do not create privileged accounts. Research parser inputs are explicit supplied bytes; analysis helpers do not execute samples. The optional PoC trainer accepts only admitted, task-matching frozen observations and writes separate candidate files; promotion is disabled. The reachability/containment view is an in-memory calculation and cannot spread to endpoints.

## Admin host setup runner

The setup panel can queue the fixed runtime-aware install/build/start request for a host watcher started with `bash install.sh --runtime auto --serve`. Its private artifacts queue binds a source/dependency catalog digest, expires unconsumed requests after five minutes and records bounded logs. Session authentication, origin checks and explicit confirmation protect the request endpoint. It accepts no shell text or caller-selected arguments. The watcher has the invoking host user’s authority and trusts the project source and private queue; it is not a public or multi-user service. The dashboard receives no container socket. Installs and image builds are not verified in this sandbox. See `ARCHITECTURE.md` and `PODMAN-SETUP.md`.
