# Optional API accounts

No API key is needed for the implemented CISA feed, retained tool-document search or local SLM inference. No API keys are bundled or shared.

If future integrations need these services, obtain keys through your own account:

- NVD: https://nvd.nist.gov/developers/request-an-api-key
- VirusTotal: https://docs.virustotal.com/reference/getting-started

These authenticated APIs are not currently connected to the dashboard. Check provider terms and data-sharing rules before integration. No repository or sample upload is implemented. Do not paste credentials into model chat or commit them to the project.
